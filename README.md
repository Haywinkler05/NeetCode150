# NeetCode 150

## Goal
The goal of going through the NeetCode 150 is to challenge my data structures and algorithms knowledge and become a better programmer. My intent is to finish all 150 problems and build the skills to approach unfamiliar LeetCode problems with confidence.

## Current Streak
5 days

## Plan
- Target pace: 2 problems a day until I finish all 150.
- All of my solutions live in this repo so I can track progress and compare old and updated versions.

## Review System
- Once every 2 weeks, I pick one problem from my review list.
- I either optimize it or finish it from a blank file within 30 minutes.
- Completing a review earns a "streak freeze" for 1 day.

**Current review list:** Valid Sudoku, Longest Consecutive Sequence, Product of Array Except Self
